# 周岁宴订单 · 使用方法

每接一单，复制一份这个文件夹，改名为「日期-客户名」，例如 `2026-1108-张满满`。

1. 把客户填好的问卷放进来，文件名以「客户问卷」开头（文字、Word、截图都可以）。问卷原件在 `C:\Users\leiwang\source\vvv-templates\客户问卷\周岁宴-需求问卷与照片清单.md`。
2. 把照片压缩包或原图放进 `photos` 文件夹。
3. 打开 Codex，把 `给 Codex 的指令.txt` 的内容粘贴进去，把 [订单文件夹名] 改成这一单的文件夹名。
4. Codex 会在 4 个关卡停下来问你：
   - 关卡 1：需求和模板对不对
   - 关卡 2：照片里谁是宝宝、爸爸、妈妈
   - 关卡 3：没把握的照片位置和配文
   - 关卡 4：样片满意吗
5. 成片和工程包都会放在订单文件夹里。

第一次在这台电脑上用时，Codex 会先装 Python 包、Node.js 依赖并下载配乐，可能会请你允许运行命令。
