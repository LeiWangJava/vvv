# Showtime · 喜剧开场 · 大屏卡点版

`VVV-Showtime` 是婚宴大屏上开席前播放的喜剧开场，**按店主提供的参考成片逐秒复刻**：每张卡的起止秒数、台词、版式、电影片段的位置都和参考片一致，总长 197.03 秒（3 分 17 秒）。主持人是一对原创的卡通新郎新娘（`toon.tsx`，SVG 关节动画），跟着 129.2 BPM 的拍子跳舞。

画面是**大屏幕上播放的正面画面**（1920×1080），不是现场拍摄的舞台视角。

## 电影片段坑位

`copy` 里的 9 个 `clip_*` 是电影片段坑位。填工程 `public/clips/` 下的视频路径：

- `clips/open.mp4`：从片段第 0 秒开始播，静音（声音来自整轨配乐）
- `clips/open.mp4@12.5`：从片段第 12.5 秒开始
- `clips/open.mp4#sound`：播放片段自己的声音

留空时显示雪花屏和“电影片段 · 某段 · 秒数”的占位。片段素材由每个工程自己放，模板包里不带。

## 声音

模板自带的 `public/music/showtime-party.ogg` 和 `public/sfx/showtime/*.ogg` 是原创合成的占位配乐和音效（`scripts/make-showtime-audio.py`，MIT）。工程用自己的整轨配乐时，把 `music.src` 换成那条音轨，并把 `sfx` 填 `关`，免得音效叠在原配乐上。
