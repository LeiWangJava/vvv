# Comedy · 喜剧开场 · 婚礼即将开始

`VVV-Comedy` 是一段 3 分 32 秒的中式婚礼喜剧开场：恶搞片头（「幸福影业出品」）→ 对联欢迎 → 来宾致谢 → 宾客须知五条（每条一个笑点）→ 新郎「放错片段」→ 新娘「不信您瞧」→ 恋爱进度条卡在 99% → 红金相框的婚纱照 → 倒计时等「信号」（大家的掌声）→ 婚礼仪式现在开始。

每个切换、笑点和音效都卡在两首配乐的节拍上：前半段 *Fun and Games*，婚纱照和倒计时换成 *When in Love*。笑点只开玩笑不伤人：不拿外貌、前任、家庭矛盾开玩笑。

## 照片

| 槽位 | 用途 |
|---|---|
| `groomKid`、`brideKid` | 新郎「放错片段」、新娘放大镜用的小时候照片 |
| `groomHero`、`brideHero` | 两人正式登场的照片 |
| `love` | 恋爱进度条的四个阶段，横幅合照 |
| `proposal` | 求婚成功 100% |
| `finale` | 「婚礼仪式现在开始」圆窗里的照片 |
| `gallery` | 1–37 张婚纱照，按套系（服装）分组，红底金框 |

初始化按导入顺序填位，先看联系表再把 ID 换到对的位置。照片记录里没有年龄时，「这是 {age} 岁的他」自动改成「这是小时候的他」。

## 文案

所有字幕都在 `props.copy` 里，Studio 右侧可直接改；`｜` 分两行。片头出品方 `studio` / `studio_en` 是虚构的「幸福影业」，可以换成新人的名字或任意恶搞名。婚纱照空白处的花字和竖排祝福语在 `gallery_tags`、`gallery_blessings`，轮流使用。

## 视频片段（可选）

每个笑点都可以换成一段视频：在 `copy` 的 `clip_*` 里填 `public/` 下的路径，可加 `@起始秒`，例如 `clips/welcome1.mp4@12.5`；只要画面不要原声就加 `#mute`。片段铺满画面，字幕照常叠在上面；有原声的片段会压低音乐。空着就用原创动画。

**最推荐新人自己拍的搞笑短片和亲友祝福。** 影视作品片段的版权由使用者负责；收费交付、在酒店公开播放、发到网上都属于公开使用。VVV 不附带任何片段。

| 槽位 | 时间 | 时长 | 字幕 | 适合的镜头 |
|---|---|---|---|---|
| `clip_welcome_1`…`_6` | 0:09.9 起，每 2.4 秒一个 | 2.4 秒 | 对联与欢迎语 | 正对镜头说话、拱手、欢呼、鼓掌 |
| `clip_arrive_1`…`_3` | 0:26.7 起，每 1.8 秒一个 | 1.8 秒 | 跑着来 / 开车来 / 坐飞机来 | 狂奔、开车、机场挥手 |
| `clip_rule_1`…`_5` | 0:38.7 起，每 4.8 秒一个 | 2.4 秒 | 每条须知的笑点 | 扔东西、大笑、大吃、开车、鼓掌 |
| `clip_groom` | 1:05.2 | 3.0 秒 | 就是他！→ 等等……放错了 | 和新郎反差很大的夸张人物；搓碟声处定格变黑白 |
| `clip_bride` | 1:22.6 | 3.0 秒 | 嗯…… → 从小就是美人胚子 | 萌宠、卡通、小朋友；不要丑化外貌 |
| `clip_signal` | 3:15.9 | 5.1 秒 | 还不能开始吗？/ 还没收到信号 | 几个人面面相觑、挠头 |

片段用 MP4（H.264）横屏 16:9，至少 720p，从起始秒开始比槽位长 0.5 秒以上。

## 配音旁白（可选）

VVV 不附带任何配音或音色。旁白稿在 [vo.json](vo.json)，每行一个 `key`，`{groom}`、`{bride}`、`{age}` 换成新人信息，`[excited]` 等是语气提示。用你有授权的声音（自己录，或有商用授权的 TTS 音色）为每行生成一个文件：

```text
public/vo/comedy/<key>.mp3
public/vo/comedy/timing.json   { "<key>": { "lead": 0.17, "speech": 2.0 }, … }
```

`lead` 是文件开头的静音秒数（播放时剪掉，让第一个字落在拍上），`speech` 是说话时长（期间音乐压低到约 16%）。没有录音的行自动跳过；`copy.vo` 填 `off` 关闭全部旁白。

## 音乐和音效

两首配乐和 12 个音效都来自 Mixkit，不随 VVV 分发：在工程里运行 `npm run music` 下载并校验（见 `public/music/sources.json`）。下载前 `validate` 会显示「待下载」。换成别的歌时先 `npm run beats` 生成节拍，再检查笑点和婚纱照是否落在想要的位置；音效按设计秒排在 `index.tsx` 的 `SOUND` 里。

配乐、音效、片段原声和可选旁白在混音前统一乘以 `0.5`，为多路声音叠加留出约 6 dB 余量；各路原有音量、对白避让以及循环版的淡入淡出仍然生效。替换音乐、添加原声或旁白后仍应检查导出音频的峰值，避免新增素材超出这份余量。

## 素材

金色剪纸（灯笼、囍字圆章、窗花圆环、祥云、角花）在 `public/assets/xy39/`，红底和金角在 `src/effects/papercut-frame/index.tsx`。字体：马善政（毛笔）、站酷快乐体、思源黑体、思源宋体、Cormorant Garamond 和 Noto Color Emoji，均为本地 OFL 字体。动效改动后用 `python3 scripts/calibrate.py --composition VVV-Comedy …` 重新测量 `hits.json`。
